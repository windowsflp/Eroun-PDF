# 이로운 PDF · Eroun PDF

**내 컴퓨터에서 문서를 처리하는 무료 PDF 편집 도구입니다. 공공기관, 기업, 개인 누구나 자유롭게 사용 가능합니다.**

PDF에 글자와 서명을 넣고, 원문을 수정하고, 페이지를 정리할 수 있습니다. 스캔 문서의 글자를 인식하는 OCR과 개인정보를 지우는 보안 가림 기능도 제공합니다.

사용 환경에 맞게 **웹판 · Windows 포터블판 · Windows 설치판**을 제공합니다. 필요한 실행 환경이 갖춰지면 **인터넷 연결 없이 PDF를 편집할 수 있으며, 문서를 처리 서버로 업로드하지 않습니다.** PDF 처리와 OCR은 사용자 기기 안에서 이루어집니다.

- 배포 버전: **0.9.0 · 사전 공개판(Pre-release)** · 2026-11-15
- 웹판: PC의 최신 **Chrome 또는 Microsoft Edge**
- 데스크톱판: **Windows 10·11, x64 · Microsoft Edge WebView2 Runtime 필요**
- 화면 언어: **한국어 · English**
- 이용 요금: **무료**

**0.9.0은 기존 기능을 모으고 배포 묶음의 자료를 정리한 사전 공개판입니다.**

## 웹판을 함께 제공하는 이유

**공공기관 등에서 프로그램 설치·실행이나 문서 편집에 제약이 있는 업무 환경을 고려해, 이미 사용 중인 Chrome·Edge로 열 수 있는 웹판을 함께 제공합니다.**

기관에 따라 새 프로그램의 설치가 제한되거나, 설치가 필요 없는 포터블 실행 파일도 차단될 수 있습니다. 프로그램을 설치하고 실행할 수 있더라도, **기관에서 인증·승인하지 않은 프로그램으로 PDF·HWPX·DOCX 등의 문서를 편집하는 작업이 제한되는 경우**도 있습니다.

웹판은 압축을 푼 폴더의 **`index.html`을 Chrome 또는 Edge에서 직접 열어 사용할 수 있습니다.** 브라우저에서 로컬 HTML 실행과 문서 열기·편집·저장이 허용된 환경에서는 PDF 작업을 위한 대안이 될 수 있습니다.

필요한 모듈·글꼴·OCR 언어 모델을 함께 제공하므로, 파일을 PC에 준비한 뒤에는 외부 웹사이트 접속이나 문서 업로드 없이 사용할 수 있습니다. PDF 처리와 OCR은 사용자 기기 안에서 이루어집니다.

> 실제 사용 가능 여부는 기관의 파일 반입 정책, 브라우저 실행 정책, 문서 접근·편집·저장에 적용되는 보안 정책에 따라 달라집니다.

## 어떤 파일을 받으면 되나요?

이 저장소의 **Releases**에서 사용 환경에 맞는 파일을 다운로드하세요.

| 배포 형태 | 이런 경우에 선택하세요 | 다운로드 파일 |
| --- | --- | --- |
| **웹판** | 설치·실행 또는 문서 편집에 제약이 있는 업무용 PC에서, 허용된 브라우저 환경으로 PDF를 작업하려는 경우. macOS에서도 사용 가능 | `Eroun-PDF-v0.9.0.zip` |
| **Windows 포터블판** | 설치 과정을 거치지 않고 독립된 프로그램 창으로 사용하려는 경우 | `Eroun-PDF-Desktop-v0.9.0-portable.zip` |
| **Windows 설치판** | PC에 설치해 계속 사용하고, PDF 파일 연결을 등록하려는 경우 | `Eroun-PDF-Desktop-v0.9.0-x64-setup.exe` |

포터블판도 `.exe`를 실행하는 프로그램이므로 실행 파일 사용이 허용된 환경이 필요합니다. 데스크톱판 두 가지에는 **Microsoft Edge WebView2 Runtime**이 필요하며, 웹판은 Chrome·Edge 브라우저에서 직접 실행합니다.

## 실행 방법

### 웹판

1. Releases에서 `Eroun-PDF-v0.9.0.zip`을 다운로드합니다.
2. ZIP 파일의 **압축을 모두 풉니다.**
3. `Eroun-PDF` 폴더 안의 **`index.html`을 Chrome 또는 Edge로 엽니다.**
4. **PDF 열기**로 문서를 선택하거나, **예제 둘러보기**로 기능을 살펴봅니다.

기본 브라우저가 Chrome·Edge가 아니라면 `index.html`을 마우스 오른쪽 버튼으로 눌러 **연결 프로그램**에서 해당 브라우저를 선택하세요. macOS에서도 같은 방식으로 사용합니다.

Windows에서는 함께 제공되는 `Eroun-PDF.cmd`로 같은 `index.html`을 기본 브라우저에서 열 수도 있습니다.

> ZIP 안에서 바로 열지 마세요. `index.html`, `js`, `css`, `vendor` 등 압축을 푼 파일과 폴더는 함께 두어야 합니다.

### Windows 포터블판

1. Releases에서 `Eroun-PDF-Desktop-v0.9.0-portable.zip`을 다운로드합니다.
2. ZIP 파일의 **압축을 모두 풉니다.**
3. `Eroun-PDF-Desktop-portable` 폴더의 **`Eroun-PDF.exe`를 실행합니다.**

`WebView2Loader.dll`은 실행 파일과 같은 폴더에 있어야 합니다. 라이선스 문서와 `third-party-source`를 포함해 압축을 푼 폴더 전체를 함께 보관하세요.

### Windows 설치판

1. Releases에서 `Eroun-PDF-Desktop-v0.9.0-x64-setup.exe`를 다운로드합니다.
2. 설치 파일을 실행하고 안내에 따라 설치합니다.
3. 설치한 이로운 PDF를 실행해 문서를 엽니다.

설치판은 PDF 파일 연결을 등록합니다. PDF를 두 번 눌러 이로운 PDF로 열고 싶다면 설치 후 기본 PDF 앱으로 선택해 사용하세요.

**데스크톱판 공통:** WebView2 Runtime이 없는 PC에서는 먼저 해당 실행 환경을 준비해야 합니다. 인터넷이 없는 PC에는 Microsoft가 제공하는 오프라인 설치 방식도 있습니다. [Microsoft의 WebView2 Runtime 배포 안내](https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution)

## 주요 기능

| 기능 | 할 수 있는 일 |
| --- | --- |
| 글자와 표시 추가 | 글자, 그림, 형광펜, 메모, 도형, 손글씨 서명, 도장 넣기 |
| PDF 원문 수정 | 지원되는 원문 줄의 글자를 바꾸거나 삭제하기 |
| 페이지 정리 | PDF 합치기·나누기, 페이지 순서 변경·회전·복제·삭제·추출 |
| 스캔 OCR | 스캔 PDF에 검색·복사용 글자를 추가하고 인식 결과 검토·수정하기 |
| 개인정보 보호 | 개인정보 찾기, 보안 가림 적용, 문서의 숨은 정보 정리 |
| 문서 작업 | 양식 채우기, 문서 비교, 책갈피, 워터마크, 머리글·바닥글·쪽 번호 추가 |
| 변환과 저장 | PDF 용량 줄이기, PNG·JPEG 저장, 이미지로 PDF 만들기, Word(DOCX)·한글(HWPX)로 변환 |
| 편집 이어가기 | `.erpdf` 작업 파일 보관, 여러 문서를 탭으로 열기 |

OCR은 **한국어, 영어, 일본어, 중국어 간체·번체**를 지원합니다. 일본어와 중국어는 가로쓰기 문서를 대상으로 합니다.

처음 사용하는 분을 위한 **쉬운 화면**, 밝은 화면·어두운 화면, 도구 찾기(`Ctrl+K`, Mac은 `⌘+K`)도 제공합니다. 화면 언어는 위쪽의 🌐 버튼에서 바꿀 수 있습니다.

## PDF 저장과 작업 보관

- **다른 사람에게 보내거나 인쇄할 때:** **PDF 저장**으로 편집 결과를 PDF 파일로 저장합니다.
- **나중에 이어서 편집할 때:** **편집 작업 보관**으로 `.erpdf` 파일을 저장합니다. 다음에 **보관한 작업 열기**로 불러오면 추가한 글자·그림과 OCR 검토 상태 등을 이어서 편집할 수 있습니다.

내보낸 PDF를 다시 열면 추가했던 글자와 그림도 원본 페이지의 일부로 취급됩니다. 계속 수정할 작업은 **PDF와 `.erpdf`를 각각 보관**하세요.

## 사용 전에 알아두세요

- **원문 수정에는 지원 범위가 있습니다.** 글자 정보가 있는 PDF의 지원되는 한 줄을 수정합니다. 문단 전체의 자동 재배치나 원래 글꼴·간격의 완전한 재현은 지원하지 않으며, 복잡한 PDF 구조에서는 수정이 제한될 수 있습니다.
- **OCR 결과는 확인이 필요합니다.** 스캔 화질, 손글씨, 표와 다단 구성에 따라 잘못 인식할 수 있습니다. OCR은 검색·복사용 글자를 추가하며, 스캔 이미지 속 글자 모양 자체를 바꾸지는 않습니다.
- **민감한 내용을 지울 때는 보안 가림을 사용하세요.** 사각형이나 그림으로 덮는 것만으로는 아래의 원문이 삭제되지 않습니다. 가릴 곳을 표시한 뒤 가림을 적용하고 저장해야 합니다.
- **서명·도장은 눈에 보이는 표시입니다.** 인증서 기반 전자서명 기능은 제공하지 않습니다.
- **중요한 문서는 원본을 따로 보관하세요.** 수정·변환·가림 후에는 저장된 결과를 확인한 뒤 사용하세요.

현재 일반 PDF 입력 한도는 파일당 **200MB**, 문서 탭 하나의 작업 원본 합계 **300MB**, **300페이지**입니다. OCR은 한 번에 최대 **10페이지**를 처리합니다. 문서 구조와 기기 메모리에 따라 실제 처리 가능한 크기는 더 작을 수 있습니다.

웹판은 PC의 Chrome·Edge를 기준으로 제공합니다. 휴대폰에서는 파일 관리자의 로컬 HTML 지원 여부에 따라 실행이 제한될 수 있습니다. Firefox·Safari는 지원 대상이 아닙니다. Windows 데스크톱판은 x64용입니다.

## 기기에 보관되는 데이터

웹판의 화면 설정·보관함·사용자가 켠 임시 저장 등은 해당 브라우저의 저장공간을 사용합니다. 데스크톱판은 앱의 로컬 저장공간을 사용합니다. 다른 실행 환경이나 기기로 자동 동기화되지 않으므로, 옮겨 작업하려면 `.erpdf` 파일을 보관해 가져가세요.

웹판에서 `index.html`을 직접 여는 방식에서는 임시 저장이 기본적으로 꺼져 있습니다. 공용 PC나 민감한 문서 작업에서는 임시 저장과 서명 보관을 꺼 두고, 필요한 작업을 `.erpdf` 파일로 직접 보관하세요. 브라우저·앱의 저장 데이터를 삭제하면 임시 작업과 보관함도 사라질 수 있습니다.

## 도움말과 문제 제보

각 배포판의 **? 버튼**에서 도움말을 열 수 있습니다. 웹판 ZIP에는 다음 파일도 포함되어 있으며 인터넷 없이 볼 수 있습니다.

- `help.html`: 그림으로 보는 한국어 도움말
- `help-en.html`: 그림으로 보는 영어 도움말
- `사용설명서.txt` / `Read me (English).txt`: 자세한 사용설명서
- `updates.html`: 버전별 변경 내역

포터블판의 시작 안내는 폴더의 `읽어 주세요.txt` 또는 `Read me (English).txt`에서 확인할 수 있습니다.

오류나 개선 의견은 이 저장소의 **Issues**에 남겨 주세요. **사용한 배포판(웹·포터블·설치판)**, 프로그램 버전, 운영체제, 웹판의 경우 브라우저, 문제를 재현하는 순서와 오류 메시지를 함께 적으면 확인에 도움이 됩니다. 예제 파일이 필요하다면 개인정보와 기밀 내용을 제거한 사본을 사용해 주세요.
